Threshold Configuration

Configure the RAG (Red/Amber/Green) thresholds for execution time color coding

Execution times above this value will be marked as RED
Execution times above this value (but below red) will be marked as AMBER
Execution times at or below this value will be marked as GREEN
Red: > {{ thresholds.redThreshold }}s
Amber: {{ thresholds.amberThreshold }} - {{ thresholds.redThreshold }}s
Green: ≤ {{ thresholds.greenThreshold }}s
