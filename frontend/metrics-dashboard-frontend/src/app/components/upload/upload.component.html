File Requirements:

  • Maximum file size: 10MB
  • Excel format: .xlsx or .xls
  • Three worksheets required: "Plans", "Overrides", "Items"
  • No special characters: !@#$%^&*()

Worksheet Structure:

Plans Worksheet:

Plan_Name, For_Date (dd-MMM-yyyy), Data_ID, Delete (D for delete)

Overrides Worksheet:

Plan_Name, Override_Name, Total_Execution_Time, On_Hold_Time, Core_Execution_Time, Request_Type

Items Worksheet:

Override_Name, Item_Name, Currency_Code, Create_Timestamp, Updated_Timestamp, Created_By, Updated_By, Item_Value_Month_1 to Item_Value_Month_20

Processing Rules:

  • Plans are processed first, then Overrides, then Items
  • If a Plan fails, all its child Overrides and Items are skipped
  • If an Override fails, all its child Items are skipped
  • For_Date must be a quarter-end date (Mar 31, Jun 30, Sep 30, Dec 31)
  • Currency_Code must be exactly 3 characters
  • Response Excel file will include Status and Reason columns
